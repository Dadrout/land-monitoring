# 3-minute jury demo script

## 0:00-0:20 — Problem
Land inspectors spend time comparing field reality with map records, while citizens do not have one fast channel to report an abandoned parcel or illegal dump.

## 0:20-0:35 — Inspector dashboard
Open the dashboard and point to KPI cards and colored parcels. Green = normal, yellow = signal under review, red = confirmed violation.

## 0:35-1:15 — Citizen report
On the phone open Telegram: Report violation → choose illegal dump → send location → send photo → write one sentence → confirm.

## 1:15 — WOW moment
Without refreshing the inspector page, show the newly received yellow report on the map.

## 1:15-1:50 — Inspector workflow
Open the report, review evidence, set the control deadline and confirm the violation. Show the status turning red, then move it to In progress and Resolved.

## 1:50-2:10 — Application status
In Telegram check KZ-2026-042 and show the current stage and explanation.

## 2:10-2:30 — Knowledge base
Show the three guided procedures: residential land, purpose change and lease extension.

## 2:30-3:00 — Scale
Explain that the MVP already has clean integration points for cadastral data, satellite monitoring, eGov and AI change detection.
